# 用語集

**同じものを別の名前で呼ばないための定義。** コード上の名前（英語）も併記する。迷ったらこの表に従う。

## 販売

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| 得意先 | 商品を売る相手。出荷先でもある | `customers` |
| 請求先 | 請求書を送る相手。得意先の1つ（支店に出荷し本社に請求する場合、本社が請求先） | `customers.billing_customer_id` |
| 見積 | 受注前に提示する金額。受注の元になる | `quotations` |
| 受注 | 得意先からの注文を受けた記録。**出荷や売上ではない** | `sales_orders` |
| 分納 | 1件の受注を複数回に分けて出荷すること | 受注明細の`shipped_quantity` |
| 出荷 | 商品を得意先へ出した記録。確定すると売上になる | `shipments` |
| 売上 | 出荷確定によって計上される収益の記録 | `sales_records` |
| 赤伝 | 誤った伝票を打ち消すための、金額を反転させた伝票 | `sales_records.reverses_id` |
| 締め | 得意先ごとの締め日で、期間中の売上をまとめること | `invoices.closing_date` |
| 請求 | 締めた売上をまとめて請求先に請求する記録 | `invoices` |
| 入金 | 得意先から受け取ったお金の記録 | `receipts` |
| 消込 | 入金がどの請求に対するものかを結びつけること | `receipt_allocations` |
| 売掛金 | 請求したが、まだ入金されていない金額 | `receivable_balances` |

## 購買

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| 仕入先 | 商品を買う相手 | `suppliers` |
| 発注 | 仕入先に注文した記録 | `purchase_orders` |
| 入荷 | 商品が届いた記録 | `goods_receipts` |
| 検収 | 届いた商品を確認し、合格数を決めること | `goods_receipt_lines.accepted_quantity` |
| 仕入 | 検収によって計上される費用の記録 | `purchase_records` |
| 買掛金 | 仕入れたが、まだ支払っていない金額 | `payable_balances` |

## 在庫

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| 在庫 | 商品×倉庫ごとの実際の数量 | `stocks.on_hand_quantity` |
| 引当 | 受注に対して在庫を確保すること。引当済みは他の受注に使えない | `stock_allocations` |
| 入出庫 | 在庫が増減した履歴。**在庫数の正はこちら** | `stock_movements` |
| 棚卸 | 実際に数えた数量と帳簿上の数量を突き合わせること | `stocktakes` |

## 金額

| 用語 | 意味 |
|---|---|
| 税抜金額 | 消費税を含まない金額。明細の金額はこれ |
| 税額 | 消費税。**税率ごとに1回だけ**四捨五入して求める |
| 税込金額 | 税抜金額＋税額 |
| 繰越 | 前回の請求額から入金額を引いた、未回収の残り |

## 紛らわしい組み合わせ

| 区別すべき言葉 | 違い |
|---|---|
| 受注 と 売上 | 受注は「注文を受けた」段階。売上は「出荷を確定した」段階。受注しただけでは売上にならない |
| 出荷先 と 請求先 | 商品を送る先と、請求書を送る先。同じとは限らない |
| 入荷 と 検収 | 届いただけか、確認して合格としたか。仕入になるのは検収した数量 |
| 在庫 と 引当可能数 | 実際にある数と、そこから引当済みを引いた数 |
| 取消 と 削除 | 取消は状態を変えるか赤伝を立てること。**削除はしない** |
